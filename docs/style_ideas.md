# 棋風・報酬・相手のタイプ（2026-11-03 のアイデア）

人と指した対局をきっかけに、「今のAIの強さは、自分と同じ考え方の相手にしか通じないのではないか」という疑問が出た。分かったことと、やるならどうするかの案をまとめる。強化学習は run w（世代376）でいったん終える予定なので、ここに書く案はどれも未実施。

## 分かったこと

数字はすべて、全部持ち駒ルールで3人とも残っている局面のもの。

### 持ち駒は多すぎると損

- **同じ局面で持ち駒を1枚足したとき**、世代360 の勝率予想の変化（約3万局面。香・桂・銀・角の平均）：0枚 +2.3ポイント、1〜2枚 +1.2、3〜4枚 ±0、5〜6枚 −0.5（78%の局面で下がる）、7〜9枚 −0.4。10枚を超える局面は少なく、傾向ははっきりしない。
- **実際の勝ち負け**（世代300〜362、16,195局）：持ち駒0枚で勝率37.6%、2枚 33.7%、5枚 27.5%、9枚 23.6%。1枚目から下がるのは、狙われて駒を打ち込まれ、それを取った人の持ち駒が増えるため（狙われているしるしでもある）。
- 駒の価値の合計（盤上＋持ち駒×1.3）でも同じで、ほかの2人より3000以上得している人の勝率は25%前後。

### 中盤に狙われるのは駒得している人

- 世代330〜362 で、40手目以降に、2人とも玉の近く（2マス以内）に敵の駒がない場面から最初に相手の玉の近くへ持ち駒を打った2,652手。打たれたのは、駒の価値の合計が多いほうが78%、持ち駒が多いほうが69%。自分の次に指す人かどうかは51%で関係なし。玉の隣の守りの駒の数も関係なし。
- 打たれた人が最後に勝ったのは27%、打たれなかった人は41%。打たれる前から、打たれる人の勝率予想は低い（平均30%と39%）。
- 序盤（中央値13手目）の最初の打ち込みは事情が違い、最初の香・桂をまだ持っている人と、自分の次に指す人（60%）が狙われやすい。

### この棋風は学習で生まれた

|---|---|---|---|---|---|
| 足場（駒の価値だけの評価） | 354手 | 5.4枚 | 44% | 0.1回 | — |
| p4 世代2〜4 | 85手 | 3.1枚 | 16% | 3.8回 | 58% |
| p4 世代20〜22 | 89手 | 2.3枚 | 7% | 7.8回 | 52% |
| p4 世代49〜51 | 105手 | 2.0枚 | 5% | 10.2回 | 52% |
| p5c 世代28〜30 | 120手 | 2.0枚 | 5% | 11.1回 | 62% |
| pmix 世代138〜140 | 116手 | 2.2枚 | 8% | 9.3回 | 64% |
| pbig2 世代355〜357 | 129手 | 2.4枚 | 11% | 18.6回 | 73% |

- 足場は「駒を抱えて打ち込まない」守り型の世界だった。強化学習を始めると20世代ほどで、持ち駒を抱えず相手の陣に打ち込む牽制型に移り、戻らなかった。
- 相手選び（駒得している人を狙う）は、そのあとゆっくり伸び、世代150ごろから横ばい。
- 持ち駒の平均は強くなっても減らない（2.1→2.4枚）。全員が持ちすぎないように打ち込むので、打ち込まれた駒を誰かが取り、平均は釣り合ったまま動かない（鏡映し）。
- 強さの違うモデルが混ざった対局（世代300〜367）では、持ち駒の平均は今の世代 1.7枚、過去の世代 2.6枚、弱いモデル 5.0枚。強いほうが余った駒を弱いほうに押しつけている、と読める。

## 疑問：人2人とAI1人だとどうなるか

- AIの打ち込みは、「もう1人も同じ相手を攻める」と見込んだ賭け。自己対局では相手も同じAIなので当たる。
- 人は「最初に退場したくない」「駒をタダで渡したくない」と考えて守りに入りやすい。守りたい人が2人いると、もう1人は乗ってこないので、AIの打ち込みはタダ捨てになる。AIの攻めが通るのは2人がかりのときで、1人での攻めは二人将棋並みの力比べになる（二人将棋はAIの弱いところ）。
- 確かめるには、人2人とAI1人の棋譜が要る（部屋の対局。2026-11-03 時点で1局）。
- 理論の上でも、3人以上のゲームには「どんな相手にもつけこまれない戦略」がない。2人のゼロサムゲームと違って、ほかの2人の動き方しだいで自分の最善が変わる。自己対局がたどり着くのは「全員が自分と同じ考え方をする世界」での最善（棋風）の1つにすぎない。

## 案1：順位の報酬のつまみ a

今の価値は勝者だけ（1位=1、2位=3位=0。open_questions.md #7）。順位に点をつける：

| 順位 | 点 |
|---|---|
| 1位 | 1 |
| 2位 | a（0〜1） |
| 3位 | 0 |

- a=0 が今のAI。a を上げるほど「3位にならない（最初に退場しない）」ことを重く見る。a は「2位確定」と「確率 a で1位、外れたら3位」が同じ価値という意味。a=0.5 で順位に素直、a=0.7 でかなり慎重、a=0.9 でほぼ退場さえしなければいい。
- 「最初に退場しない」だけ（2位=1位）にすると、読みの途中で誰かが退場した瞬間に残りの2人の点が決まり、その先を何も考えずに指すAIになる。a<1 なら1位のほうが少し高いので、1対1になっても勝つ意味が残る。
- **学習し直さずに試せる**：ネットには順位の予想（rank [N,3,3]、各自の1〜3位の確率）がすでにある。読むときの物差しを「勝者の予想」から「順位の予想から計算した点の期待値」に差しかえればよい。読みの途中で誰かが退場しても、退場した人は3位確定、残りの2人は1位か2位かの予想になるので、そのまま使える。
- 注意：順位の予想は補助ターゲットとして学んだもので、勝者の予想ほど正確かは未確認。まず当たり具合を測る。また、ネットの予想は「全員が a=0 で指す世界」で学んだものなので、守り型の相手が増えたときの先の展開は正しく予想できない。
- 予想：3位を嫌って慎重にはなるが、読みは鋭いままなので、「3位を避ける一番確実な方法＝ほかの誰かを先に退場させる」を見つけて、弱っている人を叩きに行くかもしれない。人の守り型（駒を渡したくない、捨て駒の先が読めない）とは違う可能性がある。

### 試し方

- a = 0・0.5・0.7・0.9 で、それぞれ自己対局を100局ほど（学習なし。GPU 1〜2時間）。
- 人の棋譜から、持ち駒の枚数・相手の玉の近くへの打ち込みの回数などを数え、どの a のAIが一番人に近いかを見る。
- いちばん人に近い a のAI2人と今のAI1人で指させ、タダ捨てが損になるかを見る。
- ブラウザの対戦相手（「人っぽいAI」）にするなら、ONNX に順位の予想も出させ、web/ai.js の探索で物差しを差しかえる。

## 案2：自分の a をネットの入力にする

- 自己対局で、3人の a を対局ごとにくじ引きで決める。ネットには**自分の a だけ**を見せる。相手の a は実際の対局でも見えないので、見せない。
- ネットは「相手がどのタイプか分からない中で平均して一番いい手」を学ぶ。いろいろなタイプが混ざった相手（グラデーション）の中での強さになる。相手の a の混ぜ方が「世の中にどんな人がどれくらいいるか」の想定で、人の棋譜から決められる。
- KataGo がコミやルールを入力にして、1つのネットでいろいろな条件に対応しているのと同じ考え方。
- 今のネットに入力を足し、その重みを0から始めれば、最初は今のネットと同じ強さから続けられる。ただし自己対局の量は今の学習と同じくらい要る。

## 案3：相手の a を予想する出力を足す

- 学習のときは相手の本当の a が分かるので、答え合わせができる。
- 今の局面だけでも手がかりはある（守り型は持ち駒をため込む。足場の世界では平均5枚以上、牽制型は2枚前後）。直近の手順を入力に足せば、もっと当たるはず（ネットの作り直しが要る）。
- 予想した相手の a を読みの中で使えば、「この相手は守り型っぽいから、打ち込んでも乗ってこない」と判断して、タダ捨てを自分で避けられる。
- ログインなどで同じ人を見分けられれば、前に指したときの印象を次の対局に持ちこめる。ただし相手の過去の棋譜は見返さない（人どうしなら相手の研究ノートを盗み見るのと同じでフェアでない。個人の記録を預かる量も増える）。残すのは、前回の対局が終わったときのAIの見込み（a の数字1つ）だけにする。人が「この人とは前にも指した」と癖を覚えているのと同じ程度。

### 見込みを入力にして、指しながら直す

基本は「最初の見込み → 指し手を見て直す」の2段にする。

1. **最初の見込み**：ログインしている人なら前回の対局の終わりにAIが持っていた見込み、初めての人なら「世の中の平均的な人」の a を、相手ごとにネットの入力として渡す。
2. **指しながら直す**：相手の a を予想する出力（上）で、指し手を見ながら見込みを更新し、次の手からはその値を入力に渡す。

学習では、入力に渡す見込みを本当の a そのものにしない。

- ときどきは本当の a に近い見込み（よく知っている常連の相手のつもり）。
- ときどきは平均の値だけ（初めての相手のつもり）。
- 見込みの確かさ（どれくらい当てになるか）も一緒に入力に渡すとよい。

こうすると、ネットは見込みが外れている場合も込みで使い方を覚える。見込みを信じすぎて、外れたときに大損することを防げる。
