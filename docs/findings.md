# 三人将棋でAIが見つけたこと

自己対局で学習したAI（pbig2、12ブロック×160ch）の対局を数えて分かった、三人将棋の戦い方の特徴。
人の感覚と大きく違うところが多い。数字はとくに書かないかぎり **全部持ち駒ルール** の自己対局（1世代約300局×数世代）から。

分析のスクリプトの多くは使い捨て（リポジトリには入れていない）。数え方は各節に書く。

## 1. 「賭け」の捨て駒は安い

AIは序盤から、相手の玉のそばに大駒や香を打ち込み、ただで取られるような手（以下「賭け」）をよく指す。

- **失敗しても損が小さい**：取られただけで終わった賭けで、指した人の勝率予想は約1.5ポイント（飛車でも約2.2ポイント）しか下がらない。三人では、駒を1枚損しても、残り2人のどちらか一方にだけ損をするわけではないので、二人将棋ほど痛くない。
- **3人目が乗ってくる**：賭けのあと、狙われた人をもう1人も攻める（同じ玉のそばに指す）のが50〜57%。乗ってきた賭けの約27%で、狙われた人が脱落する。
- **賭けをする人ほど勝つ**：1局の賭けの回数が0回の人の勝率は約2%、5回以上で約43%。強い局面だから賭けられる、という逆向きの効果も混ざっているので、全部が賭けの効果ではない。
- **リードしている人には乗りにくい**：攻める人が駒数で負けている・互角・リードしているときで、3人目が乗ってくる割合は 69% → 56% → 48%。トップを助けることになる攻めには乗らない。
- 人の感覚では「ただ捨て」に見えて指せない手だが、AIの読みでは割に合っている。固めて待つ人は、2人から順番に攻められて崩される。

### 次の人への「ただ捨て」（2026-10-17 の分析）

次の手番の人にただで取られる場所への打ち込みを、くわしく調べた。

- **数え方**：web/games の棋譜（標準の初期局面・全部持ち駒・3人とも生きている局面）で、持ち駒（歩以外）を打ち、次の人がすぐその駒を取り、取ったあとそのマスに打った人の駒も3人目の駒も利いていない手。60か所（うち世代182以降が42）。比べる相手は、同じ棋譜からランダムに選んだふつうの局面109か所。
- **形**：98%が次の人の玉の2マス以内、83%が王手。王手でないものは10か所で、うち7か所が緑の６八桂（青の玉の横の金を狙う位置）。
- **棋譜でのその後**：3人目も、次の人の玉の2マス以内のただの場所に駒を置いた割合が32%（ふつうの手のあとは10%）。次の人はそれも23%で取った（ふつうは7%）。

**今の学習AI（世代250、1局面3200回読み、温度0）に聞いた結果**。割合は、AIが読んだ候補手のうち「攻める手」（相手の駒を取る、または相手の玉の2マス以内に指す手）に使った訪問数の割合。

| 聞いたこと | ただ捨て（世代182以降） | ふつう（世代182以降） | ただ捨て（世代181まで） | ふつう（世代181まで） |
|---|---|---|---|---|
| 捨てない手（ただ捨て以外でいちばん読まれた手）を指したら、次の人は打った人を攻めるか | 47% | 38%（実際の手のあと） | 58% | 30% |
| 打った人がパスしたら、次の人は打った人を攻めるか | 38% | 35% | 42% | 30% |
| 打った人の局面のまま手番だけ3人目に渡したら、3人目は打った人を攻めるか | 22% | 33% | 20% | 34% |
| 同じく、3人目は次の人を攻めるか | 44% | 42% | 41% | 34% |
| ただ捨てを次の人が取ったあと、3人目は次の人を攻めるか | 49% | — | 50% | — |

- ただ捨てが出るのは、**捨てない手だと次の人に攻められやすく、3人目は打った人を狙っていない局面**。
- **評価はほぼ同じ**：今のAIも同じ局面でただ捨てをいちばんに読むのは37%。その局面では、ただ捨てと捨てない手の評価（打った人の勝率）の差は −0.1ポイント。いちばんでない局面では −4.1ポイント。今のAIなら指さない（5ポイント以上低い）ものは59か所中11か所。序盤30手（訪問数に比例して手を選ぶ）とそれ以降で、割合は変わらない。
- **推測**：次の人に自由な1手を渡すと、自分が攻められるかもしれない。駒を1枚ただで取らせれば、次の人の1手は「取る」に使われ、手番は自分を狙っていない3人目に回る。AIにとって、駒1枚の損と、次の人の1手を消す得が、ほぼ釣り合っている。けんじさんの仮説（「次の人に攻撃させないために手番を使わせる。そのあいだに3人目が次の人を攻撃してくれるかもしれない」）とおおむね合う。
- **注意**：60か所と少ない。「攻める手」の決め方は大まか。どれも相関で、AIがそう読んでいるとまでは言えない。確かめるなら、学習の自己対局（runs/ の npz）から局面を増やす。

## 2. 駒数でリードしていても勝てない

- **大差でも勝ち切れない**（世代182〜206、3人とも生きている局面、駒数＝盤上の玉以外＋持ち駒）：

| トップと2位の差 | 出た対局 | リードした人の勝率 | その局面でのAIの予想 |
|---|---|---|---|
| 12枚以上 | 193局（2万局中） | 30% | 30% |
| 15枚以上 | 42局 | 19% | 30% |
| 20枚以上 | 2局 | 0% | 60% |

- 玉が安全（取られる状態でなく、玉の2マス以内に相手の駒が1枚以下）な12枚以上のリードに絞っても、勝率は30%（AIの予想は37%）。平均の33%と変わらない。
- **持ち駒を独り占めしても勝てない**：自分の持ち駒8枚以上・他の2人は1枚以下の局面は、全部持ち駒の対局の約3分の1に出てくるが、その人の勝率は26%。10枚以上でも27%。
- **最初に脱落する人は、たいていリードしていた人**：脱落の直前、平均約9枚の持ち駒を抱えている。脱落までの最後の手の82%は、自分の玉が取られる状態での手。まだ余裕があるときの手でも、持ち駒を打つ手の半分は相手の玉のそばへの攻めで、自分の玉のそばに打つ守りは12%しかない。
  - 人なら、持ち駒が多いときは玉を固めて、相手に駒を渡さないようにする。AIは持ち駒を攻めに使い、取り返されて逆転される。
- AI同士では、20枚以上の差がほとんど出ない（2万局に2局）。人がAIとの対局で大差をつけた局面（駒数 青29・赤3・緑7 など）は、AIにとって見たことのない局面だった。対策として、実際の自己対局で12枚以上の差がついた局面から指し直す対局を2%混ぜた（[results.md](results.md) の pbig2 世代214〜229）。

## 3. 席の有利不利：全部持ち駒では緑、消滅ありでは赤が不利

### 全部持ち駒：緑の玉が1筋で挟まれる

学習が進むにつれて、緑の勝率が下がった（自己対局の実際の勝率、青 / 赤 / 緑）：

| 世代 | 実際の勝率 | 初期局面でのAIの予想 |
|---|---|---|
| 1 | 33 / 32 / 35 | 33 / 32 / 35 |
| 41 | 38 / 37 / 25 | 36 / 29 / 34 |
| 141 | 43 / 34 / 23 | 41 / 32 / 27 |
| 213 | 38 / 42 / 20 | 40 / 36 / 23 |

- 原因：**青と赤が序盤に1筋（緑の玉の筋）へ香を打ち、上下から挟む**。最初の20手で青と赤の両方が1筋に香を打つ対局が62〜75%（世代41〜213）。緑の金が香でピンされ、玉が逃げにくくなる。
- 緑の玉はそれを避けて、早めに1五を離れる（中央値は世代41で12手目、世代213で6手目）。まず2六へ、そのあと3五・2五・2四など。3五にいる割合（40〜80手目）は世代41で35%、世代213で13%と減った。
- **手番の順番ではなく、配置の問題**：手番だけ緑からにした初期局面から世代213どうしで300局指しても、青 37.7% / 赤 38.3% / 緑 24.0%。

### 消滅あり：赤が潰されやすい

- 世代198〜213の自己対局（約5,300局）で 青36 / 赤26 / 緑38。赤が最初に脱落する対局が46%（ほかのルールでは緑が43〜45%）。
- 赤が弱いのは潰し合いで終わる対局だけ：「最後の1人」で終わった対局では 青39 / 赤18 / 緑43、入玉で終わった対局では 31 / 35 / 34。
- 推測：標準の配置では、緑の飛車（2三、横に3段目）と青の飛車（9八、縦に9筋）の2本が赤を向いている。駒が消えるルールでは持ち駒で攻められず、盤上の大駒の利きがものを言う。

### 配置を変えると互角に近づく

3人とも、自分から見て同じ組み方（1段目 桂金玉金香、2段目 飛銀・銀角）にして、持ち駒なしで始める配置を試した。

| | 全部持ち駒 | 消滅あり |
|---|---|---|
| 標準の配置（自己対局） | 40 / 37 / 23 | 36 / 26 / 38 |
| 同じ組み方（ネットの評価、1600回探索） | 36 / 32 / 32 | 38 / 26 / 36 |
| 同じ組み方（世代213どうし300局） | — | 32 / 32 / 36 |

- どちらのルールでも、3人の差が数ポイントに縮まった。いちばん効いているのは、最初に1筋へ香を打てなくなること。
- ただし、持ち駒がないので序盤の自由度が低い。ネットはこの配置を学習していないので、500手打ち切りが17%出た。
- ほかの案（緑に駒を足す、緑の玉を2五へ、手番を変える）は、ネットの評価ではほとんど変わらなかった（ネットが見たことのない配置なので目安）。

### ほかのゲームとの比べ

- Board Game Arena の3人ゲーム全体（約1.2万局）では、1番手36%・2番手32%・3番手32%。カタンやアグリコラも、席の差は数ポイント。三人将棋（全部持ち駒）の17ポイントの差は大きい。
- チェスでは、強いプレイヤーほど白（先手）の有利が大きくなる。囲碁のコミも、プロが強くなるにつれて増やされてきた。三人将棋でも、AIが強くなるにつれて緑の不利がはっきりした。人同士では1筋の香の挟み撃ちはあまり出ないので、人にはそこまで問題にならないかもしれない。

## 4. ルールによる戦い方の違い

- **お裾分け**は全部持ち駒より少しだけ守り寄り。**消滅あり**はずっと守り寄りで、約半分の対局が入玉で終わる。
- 消滅ありでは駒を取っても使えないので、攻めの手段が盤上の駒に限られる。

## 5. 3人目の加わり方

- 玉を取ると、その人の駒がまとめて手に入る（全部持ち駒）。なので2体のAIは、打ち合わせなしで「一番崩しやすい玉」を同時に狙う。人から見ると共闘しているように見える。
- 攻めてこない人は、2体にとって守りに手をかけずに攻められる相手になる。固めて待つと、狙われやすくなる。

## 分析の注意

- 世代177〜181のシャードは、対局番号で局面をつなぐと別の対局の局面が混ざる。対局ごとに数える分析には使わない（局面ごとに数える分析なら問題ない）。
- 世代182〜197は1世代800局、世代198以降は「自己対局のみ」の山だけを数えている（他のモデル入り・ランダム局面・大差局面の対局は入れていない）。
- 1世代300局の勝率は±5ポイントくらいぶれる。
