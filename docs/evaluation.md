# 強さの測り方

## 対局の形式

- **1席 vs 2席**：測りたいプレイヤー1人と、同じ比較相手2人で対局する。測る側の席は毎局入れ替える（P0→P1→P2→…）。互角なら勝率33.3%。
  - 手作りエンジンの自己対戦（`tools/selfplay.js`）と同じ形式。結果を過去のデータと比べられる。
- 統計：勝率と、互角（1/3）からの z 値。132局で標準誤差は約4.1ポイント。はっきりした差を見たいときは 400局規模。
- 席ごとの勝ち数も必ず記録する（席の有利不利の分析にも使う）。

## 比較相手

| 相手 | 用途 |
|---|---|
| ランダム | 学習の最初期。ここに勝てないなら何かが壊れている |
| 1手読みの駒得優先 | 初期 |
| 手作りエンジン（`engine.js`、パラノイド＋α-β、中級2秒相当） | 本命の基準。これを超えるのがフェーズ4の目標 |
| 過去の世代のネット | 学習が進んでいるか（前の世代に勝ち越すか） |

- 手作りエンジンとの対局方法（JSのまま呼ぶか、Rustに移植するか）は open_questions.md で決める。
- ネット側は「1手あたりの訪問数」を固定して測る（例：800回）。時間ではなく訪問数で揃えると、GPUの負荷に左右されない。手作りエンジンとの比較だけは時間で揃える（同じ条件で指させるため）。

## 強さの推移

- 世代ごとに、固定の比較相手（手作りエンジン、数世代前のネット）との勝率をグラフにする。
- 余裕があれば、複数世代の総当たりから、三人対局の順位に基づくレーティング（Plackett-Luce モデルなど）を推定する。

## マイルストーン

| 段階 | 条件 |
|---|---|
| M1 | ランダム相手に 1席 vs 2席 で 90%以上 |
| M2 | 1手読みの駒得優先に 1席 vs 2席 で 70%以上 |
| M3 | 手作りエンジン（中級）に 1席 vs 2席 で 33%超（互角以上） |
| M4 | 手作りエンジン（中級）に 1席 vs 2席 で 50%超 |
| M5 | 手作りエンジン（上級4秒）に 1席 vs 2席 で 50%超 |

## 評価にかかる時間の目安

- ネット同士（訪問数800）：1局数秒〜十数秒 → 132局で数分〜数十分。
- 手作りエンジン（中級2秒）を含む対局：1局約10分 → 132局で約1時間（並列数次第）。長いので、M3以降の節目でだけ行う。
