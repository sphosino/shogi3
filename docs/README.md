# 三人将棋 自己対局学習AI 設計書

手作りの評価関数＋α-β探索から、AlphaZero / KataGo 系の自己対局学習（MCTS＋ニューラルネット）へ移行して作ったAIの設計と結果。
最初はコードを書く前の設計書として書き、実装・実験に合わせて更新している（最終更新 2026-10-30、v1.3）。

## v1.3（2026-10-30）

- 一番強いネットは **pbig2 世代296**（12ブロック×160ch、推定 約2,400）。v1.2 と同じ学習率 0.0003 で30世代続けた。世代283 からは、成り駒だらけの局面（成り駒6〜12枚・全部成った初期局面・そこからランダムに指した局面、計8,450）を「大差局面から」の山に足し、大差局面の基準を15枚以上にした。世代266 に39.3%（z=2.2）。成り駒の局面を足す前の世代282 とは互角で、ふつうの対局は弱くならなかった。Releases の重みとブラウザ版はこれ（`?model=pbig2-gen266` で世代266）。
- 人が指した対局（ブラウザのひとり対局と、mataasobo.com のみんなと指す部屋）の棋譜をサーバーにためはじめた。人が脱落したところまでの局面を、あとで学習に混ぜる（`fetch_human_kifu.py`）。

## v1.2（2026-10-29）

- 一番強いネットは **pbig2 世代266**（12ブロック×160ch、推定 約2,350）。v1.1 のあと、学習率を 0.0007 → 0.0003 に下げ、大差局面の基準を13枚以上にして16世代続けた。世代250 に39.9%（900局）、世代240 に37.3%（900局）。v1.2 の Releases の重み。
- 再開する前に、読む回数を増やすと強くなるかを測った。世代250 どうしで、200回の相手2人に、400回で61.3%、800回で78.3%。ネットの直感は、読んだ結果にまだ追いついていない（results.md）。
- 世代240〜250で頭打ちに見えたのは、ネットの大きさより学習率のせいだった部分がある。伸びなくなったら学習率をさらに下げ、それでも止まったら、ネットを大きくする（蒸留して、学習に使っていない局面での損失を今のネットと比べてから）。

## v1.1 で一度止めた（2026-10-14）

- 一番強いネットは **pbig2 世代240**（12ブロック×160ch、推定 約2,310）。v1.0（世代224）のあと、人に負けた対局で見つかった見落としを直して11世代続けた（results.md）。Releases の重みはこれ。ブラウザ版（https://sphosino.github.io/shogi3/shogi3.html）は、互角だった一番新しい世代250（`?model=pbig2-gen240` で世代240）。
- 学習の工夫の経緯（データ窓、学習率、ランダム局面・他のモデル・大差局面を混ぜる）は [results.md](results.md) の「pbig / pbig2」。
- 戦い方の発見（賭けの捨て駒が安い、駒数でリードしても勝てない、全部持ち駒では緑・消滅ありでは赤が不利、配置を変えると互角に近づく）は [findings.md](findings.md)。
- 世代250まで続けたが世代240と互角で、12ブロック×160ch では頭打ちと判断して止めた（→ v1.2 で、学習率を下げるとまた伸びた）。

## 以前の状況（2026-10-02）

- 一番強いネットは **pmix 世代121**（10ブロック×128チャンネル）。ルールをネットの入力に入れ、3つの取り駒ルールを混ぜて学習した（全部持ち駒ルールでも、全部持ち駒だけで学習したネットより強い）。世代62からは自己対局に過去の世代を混ぜ、世代102からはデータ窓を150万局面に広げた（results.md）。
- 全部持ち駒では、玉を取った人より、残りのもう1人のほうが得をする（「ちゃっかり」）。ネットはそれを理解していて、取れる玉をあえて見送ることがある（experiments.md）。
- 三人では「誰を狙うか」の流行が世代ごとに巡回し、強さが一直線に並ばないことがある。過去の世代を混ぜると、過去の流行への弱さが消えた（results.md）。
- ネットは同じ局面でもルールに応じて判断を変える（お裾分けでは駒を取る手を減らす、など。experiments.md）。

## 経緯（要約）

1. 手作りエンジンは、三人だとパラノイド探索（相手2人が組む前提）か max^N（枝刈りが効かない）しか選べず、深さを1増やしても勝率は33%→41%程度しか伸びなかった。係数の調整も1件約75分かかった。→ 自己対局学習に切り替えた。
2. Rust でルールと MCTS を作り、JS実装と14万手で完全一致を確認した。
3. 駒価値だけの「足場」の評価器で作った対局から、ネットを教師あり学習（蒸留）し、そこから自己対局の強化学習を回した（p4、小さいネット）。
4. 大きいネットに、p4 のネットの出力を教師にして蒸留し（p5c）、強化学習でさらに伸ばした。
5. 3つのルールを1つのネットで学ぶ方式に移行した（pmix）。
6. 誰を狙うかの流行の巡回への対策として、自己対局に過去の世代を混ぜた（pmix 世代62〜）。
7. 12ブロック×160ch のネットに蒸留し（pbig2）、データ窓を300万局面に広げ、学習率を下げた（世代140で約+85）。
8. ブラウザだけで動く版を作った（探索は WebAssembly、推論は ONNX Runtime Web）。検討モード、棋譜の読み込み、AIの棋譜集も。
9. 人がAIとの対局で大差をつけると、AIの評価がおかしくなることが分かった。駒を渡して大差を作る方法は効かず、ランダム局面・他のモデル入り・実際の大差局面から指す対局を混ぜて、また伸びた（世代224、世代240）。
