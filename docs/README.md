## 現状（2026-09-29）

- 一番強いネットは **pmix 世代21**（10ブロック×128チャンネル）。ルールをネットの入力に入れ、3つの取り駒ルールを混ぜて学習した。全部持ち駒ルールでも、全部持ち駒だけで学習したネット（p5c）より強い（results.md）。
- ネットは同じ局面でもルールに応じて判断を変える（お裾分けでは駒を取る手を減らす、など。experiments.md）。

## 経緯（要約）

1. 手作りエンジンは、三人だとパラノイド探索（相手2人が組む前提）か max^N（枝刈りが効かない）しか選べず、深さを1増やしても勝率は33%→41%程度しか伸びなかった。係数の調整も1件約75分かかった。→ 自己対局学習に切り替えた。
2. Rust でルールと MCTS を作り、JS実装と14万手で完全一致を確認した。
3. 駒価値だけの「足場」の評価器で作った対局から、ネットを教師あり学習（蒸留）し、そこから自己対局の強化学習を回した（p4、小さいネット）。
4. 大きいネットに、p4 のネットの出力を教師にして蒸留し（p5c）、強化学習でさらに伸ばした。
5. 3つのルールを1つのネットで学ぶ方式に移行した（pmix）。
